General Objectives

The Computer Studies syllabus is designed to enable candidates to:

  • Prepare candidates for the Board's (JAMB UTME) examination in Computer Studies.
  • Test candidates' understanding of the evolution of computing systems.
  • Test the basic concepts of the computer and its operations.
  • Test problem-solving skills, data processing, and practical skills in computing.
  • Test knowledge of system software and application software, and the operation of basic computer hardware (Input, Output, Memory and the Central Processing Unit).
  • Test the application of online resources and online skills, ethics and human issues in computing, and career prospects in computing.

  1. History of Computing

    Contents

    • Pre-computing age devices and components
    • Computing devices of the 20th century
    • Historical development behind each computing device
    • Pioneers and milestone machines (ENIAC, EDVAC, UNIVAC 1, desktop personal computers)

    Objectives — candidates should be able to

    1. Identify various computing devices: Abacus, Slide Rule, Napier's Bones, Pascal Calculator, Leibnitz Multiplier, Jacquard Loom, Babbage's Analytical Engine, Hollerith Census machine and Burrough's machine
    2. Discuss the contributions of the founders of modern computing devices (ENIAC, EDVAC, UNIVAC 1 and desktop personal computers)

  2. Classification of Computing Devices

    Contents

    • Classification by generation
    • Classification by size
    • Classification by purpose
    • Classification by type

    Objectives — candidates should be able to

    1. Relate each computer generation to its characteristic features (from the first generation to the current generation)
    2. Describe each generation by year of development, basic components/technology type, speed and storage capacity
    3. Explain the differences between micro, mini, mainframe and super computers (size classification)
    4. Differentiate between modern computer types: personal computers, desktops, laptops, tablets, hand-held, servers, workstations, mainframes, wearable, supercomputers, digital, analog, hybrid, and special/general-purpose computers
    5. State the importance and uses of these computer systems

  3. Overview of Computing Systems

    Contents

    • The two main constituents of a computer system: hardware and software
    • Computer characteristics
    • Hardware types, examples and uses
    • Logic circuits and gates
    • Software types, examples and uses

    Objectives — candidates should be able to

    1. Define a computer system in relation to its nature and programmability
    2. List the functional parts of a computer
    3. Explain computer characteristics: electronic, accuracy, speed, interactive, reliability, consistency and large storage
    4. Identify the differences between hardware and software
    5. Define hardware devices and components and list the CPU, peripherals (input/output) and storage media with their functions
    6. Explain the differences between input and output devices and describe major input devices (keyboard, mouse, scanner, joystick, light pen, voice input, digital camera)
    7. Classify keyboard keys (function, numeric, alphabetic, cursor keys) and explain mouse features and operations
    8. Explain the differences among the keyboard, mouse, light pen, scanner, digital camera and output devices
    9. Define output devices (monitor, printer, speaker, plotter), list their types/features/uses, and compare inkjet, laser and line printers
    10. List CPU components (ALU, Control Unit, Registers) and explain their functions
    11. Distinguish primary from secondary memory; list and explain RAM and ROM uses and differences
    12. Explain secondary storage functions and give examples (floppy disk, magnetic tape, hard disk, CD, DVD, USB); compare auxiliary storage by size, speed, cost and technology
    13. List units of storage measurement (bit, byte, nibble, word, kilobyte, megabyte, gigabyte, terabyte) and their relationships
    14. Define registers, bus and address; explain MDR, MAR, MBR, AC, PC and CIR; distinguish registers from main memory
    15. State the Input-Process-Output steps and the factors affecting data transfer speed (bus speed/width)
    16. Define and give the uses of logic gates (AND, OR, NOT, NOR, NAND), interpret logic equations, list gate symbols and construct truth tables
    17. Define a comparator and construct a simple comparator using XOR and NOR gates
    18. Differentiate system software from application software and list system software types (OS, utilities, middleware, device drivers, translators)
    19. Define the operating system, list its functions and user-interface types (command-line, menu, GUI), and give examples (MS Windows, LINUX, UNIX, Android, Blackberry, iPhone)
    20. Define utility software, list its functions/types and give examples (editors, anti-virus)
    21. Define translators and their functions, and distinguish interpreters, assemblers and compilers
    22. List application software examples and usage; differentiate open-source from proprietary software and in-house from off-the-shelf acquisition
    23. Explain the differences between user application programs and general-purpose application packages
    24. Give examples of common off-the-shelf application packages: word processing (MS Word), spreadsheet (Excel), database (Access), presentation (PowerPoint), graphics (Adobe Photoshop), accounting (Sage), payroll (Sage), government (Remita), banking (Fusion Banking Essence), statistics (SPSS), educational (SchoolShell) and hospital (eHospital)

  4. Data and Information

    Contents

    • Differences between data and information
    • Data representation
    • Methods of digitization

    Objectives — candidates should be able to

    1. Define data and information and list the properties of information
    2. List data types (integers, real numbers, strings, multimedia)
    3. Identify data representation and handling methods, including number bases (binary, decimal, hexadecimal)
    4. Define digitization and explain digitization processes (manual, heads-up, interactive tracing, automatic)
    5. List digitized data formats (image, audio, video, motion, text, multimedia)

  5. Word Processing Package

    Contents

    • General concept of word processing
    • Creating and saving documents
    • Editing, formatting and insertion
    • Printing
    • MS Word features, launching and basic operations

    Objectives — candidates should be able to

    1. Define word processing and give examples (MS Word, WordStar, WordPerfect, Open Word)
    2. Identify word processing features (create, save, edit, insert, print, share) and application areas (office, publishing, journalism, education)
    3. Launch MS Word and perform basic operations (create, edit, save, retrieve, print, copy/move)
    4. Use different font types and sizes, format and justify text, and use search/explore
    5. Carry out spell checking and file merging, then close MS Word

  6. Spreadsheet Package

    Contents

    • General concept of spreadsheets
    • Creating and saving documents
    • Editing, formatting and insertion
    • Printing
    • MS Excel features, launching and basic operations

    Objectives — candidates should be able to

    1. Define a spreadsheet and give examples (MS Excel, VisiCalc, SuperCalc, SPSS, Calc)
    2. Identify spreadsheet features (environment, status bar, menu bar, formula bar) and application areas (accounting, engineering, statistics, calculation, what-if scenarios, education)
    3. Launch MS Excel and define basic terms (worksheet, workbook, cell, cell range)
    4. Create, edit, save, retrieve and print spreadsheets using data types (number, label, formula)
    5. Perform arithmetic calculations using formulas and built-in functions
    6. Use different types and sizes of fonts
    7. Format, edit and print spreadsheets and draw charts, then close MS Excel

  7. Database Package

    Contents

    • Database definition and examples
    • Database organizations
    • Database format features
    • Creating a database using MS Access
    • Operations on existing databases

    Objectives — candidates should be able to

    1. Define a database and give examples (Dbase, Foxbase, MS Access, Oracle)
    2. Define basic terms (file, record, field, key, form, table)
    3. List and explain database organizations (hierarchical, network, relational) and application areas (office, home, education, government, hospital, agriculture)
    4. Explain MS Access database format features (files designed as tables; tables of rows and columns; a row holds a record; a column holds a field)
    5. Create a database: define structure, indicate field types (numeric, character, date, text), enter and save data
    6. Perform basic operations (searching, modifying, sorting, reporting, selecting, inserting) and close the database

  8. Graphics Package

    Contents

    • Definitions and examples of graphics packages
    • CorelDraw features
    • Simple design using CorelDraw

    Objectives — candidates should be able to

    1. Define graphics and give examples (Paint, Harvard Graphics, Photoshop, CorelDraw, AutoCAD)
    2. Explain CorelDraw features (LiveSketch tool, multi-monitor, healing clone tools, copy curve segments, Gaussian blur, touch-friendly GUI, stylus enhancements, import legacy workspaces, interactive sliders, custom node shapes, font filtering/search, Corel Font Manager, enhanced vector previews, handles and nodes)
    3. Activate and use existing CorelDraw files
    4. Design a business card, school logo, national flag, invitation card and certificate

  9. Presentation Package

    Contents

    • Presentation package definition and examples
    • PowerPoint features, activation and operations

    Objectives — candidates should be able to

    1. Define a presentation package and give examples (MS PowerPoint, Windows Movie Maker, Macromedia Flash, Impress, Apple Keynote)
    2. Explain PowerPoint environment features (animation painter, video editor, automatic ribbon toolbars, transitions, sections, crop tool, mask feature, preview, screenshot, smart guides)
    3. Explain the activation steps
    4. Perform operations: create a new presentation, insert pictures/text/graphs/animated content, add a slide, save, run the slide show, print and close

  10. Web Design Package

    Contents

    • Web design package definition and examples
    • Uses of web design packages
    • Web design elements using Dreamweaver

    Objectives — candidates should be able to

    1. Define web design packages and give examples (HTML, XML, Dreamweaver, RapidWeaver, Google Web Designer, Microsoft SharePoint Designer, NetObjects Fusion, Xara Web Designer)
    2. List web design elements (navigation, visual design, content, web-friendliness, interaction, information accessibility, intuitiveness, branding, turnaround time, conversion)
    3. Use Dreamweaver for social media management/marketing, website design and web development, pay-per-click (PPC) management and advert consulting

  11. Concept of Computer Files

    Contents

    • Basic terms definitions
    • File organizations
    • File access methods
    • File classifications
    • File classification criteria

    Objectives — candidates should be able to

    1. Define basic terms (file, record, field, data item)
    2. Identify and use basic data types (numeric, alphabetic, alphanumeric)
    3. Explain the relationships among file structure items (data item → field → record → file → database)
    4. Classify files by organization (serial, sequential, index, random) and access them appropriately
    5. Classify files into master, transaction and reference files
    6. Explain file classification criteria (nature of content, organization method, storage medium, date, size)

  12. Handling Computer Files

    Contents

    • Basic file operations
    • Data loss
    • Data security
    • Computer files versus manual files

    Objectives — candidates should be able to

    1. Perform basic file operations (create, delete, retrieve, insert, copy, view, update, open, close)
    2. Identify causes of data loss (overwriting, inadvertent deletion, hardware malfunction, virus attack, theft, arson, natural disaster)
    3. Use data security methods (backup, antivirus, PIN, biometrics, passwords, proper labelling, CCTV/physical security, fire extinguisher, smoke alarm)
    4. Compare the advantages and disadvantages of computer files versus manual files (security, access speed, setup cost, maintenance, electricity supply)

  13. Booting and Shutting Down Process

    Contents

    • Definition of booting
    • Types of booting
    • Booting and shutdown steps

    Objectives — candidates should be able to

    1. Define booting and list its types (cold booting and warm booting)
    2. Explain the differences between cold and warm booting
    3. Explain the booting and shutdown steps

  14. Computer Maintenance

    Contents

    • General system cleaning
    • Battery and UPS maintenance
    • Hardware and software maintenance
    • Data recovery

    Objectives — candidates should be able to

    1. Perform general computer system cleaning
    2. Charge and replace batteries for portable systems and UPS
    3. Clean drive lenses
    4. Perform simple hardware and software maintenance
    5. Recover data from crashed systems

  15. Computer Room Management

    Contents

    • Sitting arrangement
    • Positioning of equipment
    • Environmental conditions
    • Laboratory rules

    Objectives — candidates should be able to

    1. Define a proper sitting arrangement
    2. Position the monitor, keyboard, CPU, mouse and peripherals appropriately
    3. Ensure proper computer room illumination
    4. Maintain a dust-free environment and keep liquids away from the computer room
    5. Keep strictly to laboratory rules and regulations

  16. Communication Systems

    Contents

    • ICT definitions and acronym
    • ICT types and examples

    Objectives — candidates should be able to

    1. State the full meaning of ICT and define it
    2. List ICT types (broadcasting, telecommunication, data network, information systems, satellite communication)
    3. Give broadcasting examples (radio, television, satellite broadcasting)
    4. List telecommunication types (PSTN land line, mobile phone system, CSPT, satellite telephone system, fixed wireless telephone system)
    5. List data network types (PAN, LAN, MAN, WAN, intranet, internet)
    6. List information system types (data processing system, Global Positioning System)

  17. Application Areas of ICT

    Contents

    • ICT application areas
    • ICT-based devices

    Objectives — candidates should be able to

    1. Define ICT application areas (teleconferencing, video conferencing, telecommuting, telecomputing, messaging, information search/retrieval/archival, e-learning, telemedicine, e-commerce, e-government, e-library)
    2. List ICT device types (mobile phones, computers, ATMs, dispensing machines, point-of-sale machines, automated cash registers, radio sets, television sets, scanners)

  18. Internet

    Contents

    • Internet term definitions
    • Internet browsers
    • Browser features
    • Internet services

    Objectives — candidates should be able to

    1. Define the internet
    2. Define and illustrate terms: home page, browse, browser, chatroom, cybercafe, HTTP, HTML, ISP, webpage, website
    3. Access the internet through browsers (Internet Explorer, Opera, Firefox, Google Chrome and others)
    4. Explain browser features (title bar, menu bar, tool bar, address bar, icons, search bar, Uniform Resource Locator (URL)/hypertext link)
    5. Describe the use of internet services (e-mail, e-mail discussion groups, instant messaging/chats, virtual meeting platforms, File Transfer Protocol (FTP), World Wide Web (WWW), search engines, chatting)

  19. Electronic Mail

    Contents

    • Definition of electronic mail
    • Email services
    • Email creation and opening steps
    • Email address features

    Objectives — candidates should be able to

    1. Define electronic mail and chatting
    2. List e-mail services (creating an e-mail address, composing e-mail, sending/receiving e-mail, adding attachments, chatting, creating a mailing list/group)
    3. Explain email address features (e.g. user@DomainName) and the components of a domain name

  20. Networking

    Contents

    • Definition of networking
    • Network types
    • Network topologies
    • Network devices

    Objectives — candidates should be able to

    1. Define a computer network
    2. List and define network types (PAN, LAN, WAN, MAN, intranet, extranet, internet)
    3. Explain the differences between network topologies (star, bus, ring)
    4. Define and explain the uses of network devices (hub, modem, switch, router, gateway, repeater, access point, network interface card)

  21. World Wide Web (WWW)

    Contents

    • Definitions and acronym meanings
    • Brief history of the WWW
    • Basic terminologies
    • Protocols
    • Advantages and disadvantages
    • Website navigation
    • Web development software
    • Email versus website

    Objectives — candidates should be able to

    1. Give the full meanings of WWW, HTTP, HTTPS, HTML and XML and explain the history of the WWW
    2. Explain basic terminologies (www, website, homepage, protocol)
    3. Define protocol and list types (HTTP, HTTPS, FTP)
    4. List the uses, benefits and disadvantages of the WWW (including identity theft, cyberbullying, fake news, hacking, spam)
    5. Navigate through websites such as www.jamb.org.ng, www.waec.org.ng, www.neco.org.ng, www.ui.edu.ng, www.jgiyc.com and www.google.com
    6. Use web development software (FrontPage, WordPress, Dreamweaver, Photoshop, Google Web Designer)
    7. Differentiate between an email address and a website address

  22. Cables and Connectors

    Contents

    • Network cables and connectors
    • Computer cables and connectors

    Objectives — candidates should be able to

    1. Identify network cables (twisted pair, coaxial, fibre optics) and connectors (RJ45, RJ11, T-connectors)
    2. Identify computer cables (power, data, printer, USB, monitor, serial, parallel) and connectors (male and female)

  23. Programming Language

    Contents

    • Definition and classification of programming languages
    • Advantages and disadvantages of the different language levels

    Objectives — candidates should be able to

    1. Define a programming language
    2. Identify programming language classifications: machine language, assembly language and high-level language (BASIC, C, Java, Fortran, Python, Perl)
    3. Give the advantages and disadvantages of machine, assembly and high-level programming languages

  24. High Level Languages (HLL)

    Contents

    • HLL classifications
    • HLL characteristics
    • Translators

    Objectives — candidates should be able to

    1. Classify high-level languages (scientific, general purpose, business, object-oriented, procedural, artificial intelligence, string processing, domain-specific, scripting, systems, visual, esoteric)
    2. Explain HLL characteristics (require translation, portable, English-like and easy to read/write/maintain, use data types and control structures, programmer friendly)
    3. Define translators and their basic types (interpreters and compilers)

  25. Algorithm and Flowcharts

    Contents

    • Definitions of algorithm and flowchart
    • Functions of an algorithm
    • Properties of an algorithm
    • Flowchart symbols

    Objectives — candidates should be able to

    1. Define an algorithm and a flowchart
    2. State the functions of an algorithm (perform calculations, data processing, automated reasoning)
    3. State and explain algorithm properties (input, output, definiteness, effectiveness, finiteness)
    4. Identify flowchart symbols (start, input/output, process, decision, stop, loop, continuation)
    5. Draw flowcharts for programming problems

  26. Programming Language Structure

    Contents

    • Basic statements
    • Arithmetic and string operators
    • Subunits
    • Primitive and non-primitive data

    Objectives — candidates should be able to

    1. Identify language features and syntax (keywords, variable types, constants/literals, numeric, string/alphanumeric)
    2. Identify basic statements (input, output, processing, comments, subunits such as functions/procedures/methods/subroutines, and statements such as iteration, conditional, assignment, dimension)
    3. Define arithmetic operators and expressions, string operators and expressions, and built-in functions
    4. Define primitive data (integer, float, Boolean, character) and non-primitive data types (arrays, classes, string)
    5. Define complex data structures (trees, graphs, linked lists, objects)

  27. Program Development

    Contents

    • Definition of a program
    • Characteristics of a good program
    • Precautions in program development
    • Program development steps

    Objectives — candidates should be able to

    1. Define a program and list the characteristics of a good program (accuracy, readability, maintainability, efficiency, generality, clarity)
    2. State program development precautions (be patient, do not skip steps, follow the order of execution)
    3. Explain the program development steps (problem definition, analysis, design, coding, compilation, testing/debugging, documentation, maintenance)
    4. Give examples of interpreted programs (BASIC, Java, Python) and compiled programs (COBOL, FORTRAN, C, C++)

  28. System Development Life Cycle (SDLC)

    Contents

    • Definition of the SDLC
    • Stages of the SDLC

    Objectives — candidates should be able to

    1. Define and describe the System Development Life Cycle
    2. Explain the SDLC stages: preliminary study (identification of the problem, recognition of the need), feasibility, analysis, design, implementation (coding, testing, documentation and delivery), maintenance and review
    3. Draw an SDLC diagram

  29. Artificial Intelligence (AI)

    Contents

    • Definition of AI
    • Branches of AI
    • Applications of AI

    Objectives — candidates should be able to

    1. Define artificial intelligence
    2. Identify the branches of AI (machine learning - supervised, unsupervised and reinforcement; neural networks; expert systems; fuzzy logic; natural language processing; deep learning)
    3. List AI application areas (robotics, e-commerce, navigation, human resources, healthcare, agriculture, gaming, automobiles, social media, marketing)

  30. Fundamentals of Robotics

    Contents

    • Definition of robotics
    • Main robot components
    • Types of robots
    • Robot application areas
    • Advantages and disadvantages of robots

    Objectives — candidates should be able to

    1. Define robots and robotics
    2. Identify the main robot components (control system, sensors, actuators, power supply, end effectors)
    3. Mention robot types (humanoid, autonomous, teleoperated, augmenting robots)
    4. Itemize robot application areas (logistics, manufacturing, home, travel, healthcare, security, space exploration, entertainment, agriculture, food preparation, military, customer service)
    5. State the advantages and disadvantages of robots

  31. Computer Ethics and Cyber Risks

    Contents

    • Ethical issues: computer-related crime
    • Responsibility for computer failure
    • Protection of computer property, records and software
    • Privacy of the company, workers and customers
    • Computer security
    • Cyber risks and protection

    Objectives — candidates should be able to

    1. Define computer-related crime and state examples (compromising computer systems, hacking, theft)
    2. List methods of preventing unauthorized access (user identification, passwords) and methods of protecting computer resources (electronic and manual)
    3. List methods of protecting privacy by law and electronically
    4. Define computer security and identify its types (network, internet/cyber, application, data, information and end-user security)
    5. Identify appropriate security tools (firewalls, antivirus software, encryption) and information security dimensions (confidentiality, integrity, availability - CIA)
    6. Identify categories of application threats and their characteristics (input, authorisation, session management, parameter tampering) and mention network security issues (unauthorised intrusion; rules and configurations that protect confidentiality, integrity and accessibility using software and hardware)
    7. List network security methods (antivirus, application security, behavioural analytics, data loss prevention, email security, firewalls, mobile device security, network segmentation, SIEM, VPN, web security, wireless security, network access control)
    8. List cyber security threats (cybercrime, cyber-attack, cyberterrorism, malware, virus, trojans, spyware, ransomware, adware, botnets, SQL injection, phishing, man-in-the-middle attack, denial of service, Dridex, romance scams, Emotet malware)
    9. List cyber security safety tips (regular software/OS updates, use antivirus, use strong passwords, avoid unknown attachments/links, avoid unsecured public Wi-Fi)

  32. Potentials for Higher Studies in Computing

    Contents

    • Career paths in computing
    • Career prospects and entrepreneurship in computing

    Objectives — candidates should be able to

    1. List possible computing career paths (software developer, software test engineer, programme analyst, system developer, web developer, software development engineer, computer system analyst, database administrator, system administrator, system engineer, system analyst, network engineer, business analyst, program manager, IT specialist, data analyst/scientist, AI and robotics, system security analyst, digital forensic analyst, mobile app developer, ICT manager, blogger, e-marketer, social media manager, ICT educator, career in academia, private entrepreneurship, internet police, IT user support/desk officer, ICT librarian, computer instructor)

Frequently Asked Questions

Has the JAMB Computer Studies syllabus changed for 2027?
No. JAMB has not published a separate Computer Studies syllabus for the 2027 UTME. As of 21 November 2026, the Computer Studies PDF on IBASS, JAMB's syllabus portal, is byte for byte the same 23-page file it served on 27 August 2026. If JAMB replaces it when registration opens, this page and its date change with it.
How is the JAMB UTME Computer Studies syllabus structured?
It is organized into nine sections (A to I): Evolution of Computing; Fundamentals of Computing; Computer Application Packages; Managing Computer Files; Computer Maintenance and Safety Measures; Information & Communication Technology (ICT); Developing Problem-Solving Skills; Artificial Intelligence (AI) and Robotics; and Computer Ethics and Human Issues. The official PDF numbers 36 topic headings. Some headings share one set of objectives (Definition, Branches and Applications of AI; Ethical Issues, Computer Security and Cyber Risks), so this page groups them, giving 32 topics. Each topic lists the content to study and the objectives candidates should be able to demonstrate.
